# 如何启动！

#### **一、 技术栈**

**后端技术**

- **核心框架**: Spring Boot (2.x / 3.x, 基于 `pom.xml` 配置)
- **持久层**: MyBatis, MyBatis-Plus
- **数据库**: MySQL
- **缓存**: Redis
- **构建工具**: Maven
- **Web 服务器**: Tomcat (内嵌)

**前端技术 (管理端)**

- **核心框架**: Vue.js
- **工程化**: Node.js, Webpack/Vite

**小程序技术 (用户端)**

- 原生微信小程序 或 uni-app
